# Version 2 Implementation Notes

Version 2 follows `v2_update.md`.

Mountain Scope has moved from a manual workflow dashboard into a curriculum-driven learning roadmap and verification system.

## Implemented Capabilities

- Import curriculum text into structured JSON.
- Store curriculum as the source of truth.
- Display phases, projects, topics, and derived completion.
- Open a dedicated topic workspace.
- Show overview, resources, mentor chat, verification, and notes tabs.
- Generate dynamic topic resource links.
- Audit public GitHub repositories against stored completion criteria.
- Store audit evidence and confidence.
- Distinguish AI-verified progress from manual completion.
- Calculate overall progress from topic completion.
- Expose the workflow through Custom GPT Actions.

## Topic States

- `complete`
- `partial`
- `not_verified`
- `missing`

## Design Rules

- Curriculum data remains authoritative.
- Audits must produce evidence.
- Manual overrides must be visible.
- Topics are never locked behind previous topics.
- Progress is calculated, not guessed.

## Future Work

- Robust PDF extraction service.
- Hosted AI model integration.
- Private GitHub access.
- Deeper repository source-code analysis.
- Better curriculum version-diff UI in the dashboard.
