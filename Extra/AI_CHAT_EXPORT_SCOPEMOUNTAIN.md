# Mountain Scope AI Development Notes

Mountain Scope originally explored learning-path organisation. The current Version 2 specification moves the product into a curriculum engine that imports structured curriculum material, stores it as the authority, and verifies implementation progress with evidence.

## Useful Lessons Preserved

- AI works best when the source material is explicit.
- The system should avoid invented learning objectives.
- Clear requirements produce better implementation boundaries.
- Progress should be visible and structured.

## Current Direction

The active product now supports:

- curriculum import
- structured roadmaps
- topic workspaces
- resources
- topic mentoring
- repository audits
- transparent manual overrides
- calculated completion

The official curriculum remains the source of truth. AI is a parser, mentor, recommender, and auditor, not the authority.
